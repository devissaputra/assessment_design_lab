# Research protocol

## Project

Assessment Design Lab

## Questions

1. Which items are too easy, too difficult, or weakly discriminating?
2. What reliability evidence is appropriate for a given assessment design?
3. How can item diagnostics feed back into instructional design?

## Baseline methods

- item difficulty
- upper and lower group discrimination
- Cronbach alpha
- response matrix checks
- assessment review signals

## Evidence to collect

Start from the current transparent baseline and record every transformation needed to produce item difficulty, item discrimination, and internal consistency estimates. Keep a clear boundary between synthetic demonstration data and any future empirical dataset.

## Validation

Use a sufficiently large response matrix, report uncertainty around item statistics, and compare flagged items with an independent expert review. Reliability should be interpreted in the context of the assessment design.

## What counts as a useful result

The next study should use a real assessment with documented item content and enough responses for stable estimates. I would add distractor analysis and compare statistical flags with expert item review instead of treating a threshold as an automatic decision.

## Threats to validity

Small samples, multidimensional tests, speeded responses, guessing, and poorly matched total scores can distort classical item statistics.
